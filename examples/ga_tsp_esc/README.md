# TSP ESC Visual Demo

Animated travelling-salesman GA demo using `std::esc`.

- Magenta: initial random route
- Green: current best GA route
- Yellow: city nodes
- White: overlap points
- Update interval: `100ms`
- Runtime: about `55s` unless exited with `q`

Run:

```bash
./examples/ga_tsp_esc/run_demo.sh
```
